# Aturan Desain: Larangan Menggunakan Bentuk Diamond / Belah Ketupat (No Diamonds)

## Konteks
Sesuai arahan desain Velosha (cartoon / retro neo-brutalist), elemen dekoratif berbentuk diamond / belah ketupat (`rotate-45` square, simbol `◆`, atau aksen belah ketupat) dilarang digunakan di seluruh komponen antarmuka.

## Aturan Spesifik:
1. **Footer & Heading**:
   - Dilarang menambahkan aksen bullet atau aksen kotak berputar 45 derajat (`rotate-45`, `rotate-[45deg]`, diamond shape) pada judul footer, header section, atau label kategori.
   - Gunakan tipografi bold bersih atau pemisah titik bulat sederhana (`•` / `rounded-full`) jika memang diperlukan pemisah.
2. **Pemisah Teks Melengkung (Wavy / Arc Text)**:
   - Dilarang menggunakan simbol diamond `◆` sebagai pemisah kata.
   - Gunakan bullet bulat standar `•` berwarna oranye (`#DE7119`) atau spasi berjarak (`dx="14"`).
3. **Banner Pemisah / Dekorasi Acak**:
   - Dilarang menyisipkan banner pemisah rute yang tidak jelas atau berornamen diamond/belah ketupat di antara konten utama dan footer.
